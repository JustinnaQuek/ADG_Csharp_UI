# Multichannels SMU UI

This is a **4-channel Source Measure Unit
(SMU) control panel** — a WPF UI for sourcing a voltage on multiple channels
and watching the measured voltage/current come back live. 

# Requirements
- Windows
- .NET 10 SDK
Run the application
From the repository root, run:

dotnet run --project .\src\SmuMultichannelUi.csproj
Alternatively, open the repository folder in Visual Studio, select SmuMultichannelUi as the startup project, and run it.
